Process

How the system works

  1. 1

    Write the contract

    Every component starts as a JSON contract: props, variants, states, anatomy, tokens, and a11y rules — all specified before any code.

  2. 2

    Build the component

    TSX is generated from the contract. The contract is the source of truth; the code is the artifact.

  3. 3

    Create in Figma

    ComponentSets in Figma mirror contract variants 1:1. Figma node IDs are anchored back into the contract.

  4. 4

    Ship and compose

    Components compose into landing pages, dashboards, auth flows — all from the same contract-first foundation.
